# Lessons Learned

## 2026-10-21: React effect returned a value (blank screen on navigation)
- **Mistake:** `useEffect(() => window.scrollTo(0, 0), [pathname])`. The one-line arrow returns whatever `scrollTo()` returns. Newer Chrome returns a Promise, React treated it as a cleanup function, and the app crashed on every page change.
- **Lesson:** always give `useEffect` a block body (`() => { ... }`) unless you really mean to return a cleanup function.
- **How it was caught:** the backend/API tests could not see it. Only the real-browser UI test (headless Chrome) found it. Keep a browser test in the test phase.

## 2026-10-21: npm lockfile made on Windows broke the Linux Docker build
- **Mistake:** `package-lock.json` generated by npm 11 on Windows had entries without a version for Linux-only optional packages (`@tailwindcss/oxide-*`), so `npm ci` in `node:22-alpine` failed with "Invalid Version".
- **Lesson:** generate or refresh lockfiles with the same Node/npm version as the Docker image (for example inside a `node:22-alpine` container), and always run a Docker build before finishing a dev phase.
